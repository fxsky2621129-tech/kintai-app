# v8.7.0 法改正 虎の巻

既存の勤怠・改善基準チェッカーに、2024年・2026年・2028年までの施行準備を確認する9項目を追加しました。2026年9月19日に厚生労働省・国土交通省の資料を確認し、各カードに出典を付けています。許可更新・適正原価制度の施行日は、公布後3年以内の政令で定める日として記載しています。

## 使い方

- 上部の「法改正 虎の巻」から開き、年・キーワード・未確認で絞り込みます。
- 確認チェックと日時は端末内に保存します。内容が改訂された項目はrevisionを増やすことで再確認を求められます。
- 「バックアップ」「復元」は勤怠と確認状態を一緒に扱います。旧版のバックアップに確認状態がない場合は現在の確認状態を保持します。「全データ削除」は確認状態も削除します。
- AndroidのChromeでHTTPSのURLを開き、オフライン準備完了後、「︙」からホーム画面に追加またはインストールします。APKではありません。
- 新版の準備ができると「最新版を開く」が表示されます。初回起動には通信が必要です。公式資料のリンクはオフラインでは開けません。

## データ・通信

既存の `truck_kintai_v8_*` 保存キーは維持しています。確認状態は `truck_kintai_v8_law_checks` に保存します。ブラウザーのデータ消去・端末紛失では失われます。Sites版など別のURLとは保存領域が異なり、自動移行されません。

勤怠・確認記録・GPS座標をアプリから外部送信しません。旧版の国土地理院へのGPS住所照会を停止し、市区町村データも同梱しました。新しいGPS打刻は座標を表示し、既存記録の住所は保持します。GPSの取得可否や端末・OS自体の位置サービス通信は端末側の設定に依存します。配信元へのファイル取得通信と、利用者が公式資料を開いた場合の外部サイトへの通信はあります。

`localgovjp.json` は [Code for FUKUI/localgovjp](https://github.com/code4fukui/localgovjp) のCC0データから、pref・city・cidの3項目を同梱しています（取得日2026-09-19）。ライセンス：https://creativecommons.org/publicdomain/zero/1.0/

## 配置・検証

静的ファイル一式を同じディレクトリに置きます。相対URLなのでGitHub Pagesの `/kintai-app/` 配下にも対応します。公開範囲の設定変更は不要です。

```sh
node regression.cjs
node gps-rules-tests.cjs
node law-tests.cjs
```

ブラウザー検証はPlaywrightとChromiumを用意して `node browser-tests.cjs` を実行します。必要に応じて `PLAYWRIGHT_MODULE`（Playwrightモジュールのパス）と `CHROME_PATH`（Chromium系ブラウザー実行ファイル）を指定できます。検証用サーバーはlocalhostの空きポートで起動し、終了時に閉じます。

モバイル幅のChromiumで、確認状態の再読込・オフライン起動・バックアップ復元・保存失敗時の表示・外部リクエスト不在を確認しています。Android実機へのインストールそのものは未検証です。
