# 改善基準告示 簡易確認 v8.8.0

既存の勤怠アプリの先頭に、保存済み打刻を読む簡易確認画面を追加しました。同じ公開URL・端末・ブラウザーなら、従来の勤怠・GPS記録を引き継ぎます。

## 使い方

1. 従来の「始業」「作業打刻」「終業」を使います。時間の二重入力は不要です。
2. 「簡易確認」の日付を選び、日別・週間・月間を切り替えます。
3. 過去の休日は「休日・特例の確認」から記録します。勤務がある日・今日・未来の日は休日登録できません。
4. 宿泊を伴う長距離運行や予期し得ない事象は、該当日の確認フラグを保存できます。
5. 「バックアップ」で勤怠と休日・特例確認をまとめて保存できます。

## 判定の範囲

- 通常基準の「範囲内・注意・基準超過・確認待ち」と理由を表示します。
- 24時間の拘束、勤務前後の休息、連続運転、2日平均、固定した2週間の運転、月・暦年の拘束を確認します。
- 2日平均は前日の始業から48時間と対象日の始業から48時間の運転区間を集計します。同日に複数勤務がある場合は、その日の最初の始業を使います。前日が休日なら午前0時を参考起点とします。
- 簡易確認では、勤務・休日の記録がない日を不明として扱います。期間が終了していない、必要な記録が不足している、次の始業が未記録等の場合、超過が判明している項目を除き確認待ちになります。一部だけ打刻した日の打刻漏れまでは検出できません。
- 月間・年間拘束と2週間の運転は、従来と同じ始業日基準です。月跨ぎ勤務も始業月に計上します。週は月～日、年は1～12月です。会社の起算日が異なる場合は参考値です。
- 運転中断は、既存エンジンの休憩区間のみを算入する厳格確認です。荷役・待機は自動算入しません。休憩の分割・短時間中断は理由欄にも表示します。
- 長距離特例は確認フラグと必要条件の案内までです。週内すべての運行距離、宿泊場所、回数、運行後の回復休息を自動検証しないため、フラグだけでは15時間・9時間の通常判定を解除しません。
- 予期し得ない事象の時間控除、労使協定による月・年の延長、フェリー、2人乗務、分割休息等は自動適用しません。これらを含む法令適合性の確定判定ではありません。
- 従来の月間勤務表・CSVの集計ロジックは維持しています。従来の表は未記録日を0として扱うため、新しい簡易確認の確認待ち表示や48時間窓の2日平均と異なることがあります。

## 配置と更新

GitHub Pagesの既存リポジトリにこの変更を反映します。公開後、従来のURLを開き「最新版を開く」が出たら押してください。表示バージョンは8.8.0です。ブラウザーのサイトデータは削除しないでください。

新しいquick-check.jsはサービスワーカーのキャッシュ対象です。旧版と新版のHTML・スクリプトが混在しないようキャッシュ名も更新しています。休日・特例確認は従来settingsキー内のquickCheckに保存し、通常設定の保存・バックアップ・復元・全削除に対応しています。
