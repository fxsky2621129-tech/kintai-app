# 簡易運行チェック v8.8.0

既存の始業・終業・作業打刻から日別の総合判定と週間一覧を表示します。追加の勤務入力は不要です。画面下部の「今日・週間・月間・設定」から移動できます。保存キーを変更していないので、同じGitHub Pages URL・ブラウザーの既存データを利用できます。

## 利用方法

1. いつも通り始業・作業・終業を打刻します。
2. 上部の「今日の運行チェック」で、拘束・運転・連続運転・休息・2日平均・2週平均・月間／年間拘束を確認します。日付を変えると過去の運行を確認できます。
3. 設定の「集計の入力完了期間」に、勤務をすべて入力済みで、記録のない日を休日・運転なしと確認できる期間を指定します。未確認の期間や未来の期間を含む集計は、上限内でも適合を確定しません。期間の終了に合わせて更新してください。
4. 長距離運行や予期し得ない事象があれば、日別画面の「この勤務の特例・確認メモ」に保存します。複数勤務の日は直近の勤務が対象です。既存のバックアップ／復元に含まれます。

## 判定の範囲

- 通常基準のOK・注意・違反に加え、記録不足／集計中は判定待ちを表示します。総合判定が注意・違反でも、未確定の項目数と理由を別に表示します。
- 2日平均は、前日の実際の始業から48時間、および当日の各始業から48時間に重なる運転区間を使います。両側の平均が9時間を超えると違反、一方の入力完了範囲の平均が9時間以内なら適合です。同じ日の複数始業も個別に確認します。前日が複数勤務の場合は最初の始業を起点にします。前日記録がない場合は前側の平均を未確認とし、当日起点の48時間による確認を待ちます。
- 2週平均は設定した起算日から14日間。境界をまたぐ運転区間は期間内の時間のみ算入します。月・年・週間一覧の時間は、従来どおり始業日に計上します。年間は暦年です。会社の集計起算日と異なる場合は別途照合してください。
- 連続運転は既存の厳格確認を利用し、休憩による中断を計算します。荷役・待機や短い中断の例外は個別確認です。勤務内の休憩総計が30分でも、どこで中断したかが不明ならリセットできません。
- 長距離特例、予期し得ない事象、労使協定による月310時間・年3400時間等は自動適用しません。条件・記録の確認が必要です。チェックを入れても通常基準の超過は消さず、総合表示で「通常基準超過・特例要確認」と区別します。
- フェリー、2人乗務、分割休息、隔日勤務等の特例は未対応です。
- 既存のGPS・勤怠・法改正虎の巻は継続利用できます。データは端末のブラウザー内に保存され、同じURLでも端末間の自動同期はありません。

## 検証

Node.jsで `node regression.cjs`（33件）、`node gps-rules-tests.cjs`（25件）、`node law-tests.cjs`（7件）、`node quick-check-tests.cjs`（14件）を実行。

Playwrightで `node browser-tests.cjs` と `node quick-check-browser-tests.cjs` を実行。必要に応じて `PLAYWRIGHT_MODULE` と `CHROME_PATH` を指定します。モバイル幅360/393/768px、保存・復元、オフライン再読込、編集中のメモ保持、既存画面、JavaScriptエラーなしを確認しています。画面検証用の勤務はテストブラウザー内のみのサンプルです。

## 更新

PRをマージし、GitHub Pagesの公開完了後、同じURLを開きます。既存のサービスワーカーがある場合は、新版の準備ができてから「最新版を開く」を押してください。更新前に端末のバックアップを保存しておくと復元できます。
