勤怠・改善基準チェッカー v8.1.0 - GitHub Pages公開用（作業別GPS・フォルダーなし版）

【アップロード前の重要事項】
・ZIPファイル自体ではなく、ZIPを展開した「中身」をリポジトリ直下へアップロードしてください。
・展開後の9ファイルは、すべて同じ階層に入っています。フォルダーのアップロードは不要です。
・ファイル名の大文字・小文字は変更しないでください。

【公開方法】
1. GitHub の kintai-app リポジトリを開く
2. リポジトリが空の場合は「uploading an existing file」を押す
   既にファイルがある場合は Add file → Upload files を押す
3. 旧版がある場合は index.html / app.js / style.css / sw.js / manifest.webmanifest / gps-addon.js を削除
4. このZIPの中にある9ファイルをすべて選び、リポジトリ直下へアップロード
5. Commit changes を押す
6. Settings → Pages → Build and deployment を開く
7. Source は「Deploy from a branch」、Branch は「main / (root)」を選び Save
8. 公開完了後、次の固定URLを開く
   https://fxsky2621129-tech.github.io/kintai-app/

【更新後の確認】
・画面上部と「データ保護・アプリ」に v8.1.0 と表示されれば更新完了です。
・旧画面が出る場合は、固定URLを再読み込みしてからブラウザを一度閉じ、もう一度開いてください。
・既存データを守るため、ブラウザの「サイトデータを削除」は行わないでください。

【スマートフォン】
・必ず上記の https:// で始まる固定URLを開いてください。
・位置情報は「許可」にしてください。取得に失敗しても打刻自体は保存されます。
・Chromeメニューから「アプリをインストール」または「ホーム画面に追加」を選べます。

【GPS記録】
・始業、終業、運転、待機、荷積み、荷卸し、休憩、その他の各ボタンでGPSを取得します。
・作業を切り替えた位置は、前作業の終了位置と次作業の開始位置の両方へ保存します。
・住所が同じでも移動を確認できるよう、緯度経度、精度（±m）、取得時刻を必ず表示します。
・精度50m以内を目標に最大15秒間測定し、その間で最も良い位置を採用します。
・作業別GPSは作業中の履歴、勤務履歴、月間勤務表、CSV、バックアップに保存されます。

【データ】
・同じGitHub Pages URLに旧v6または旧v7のデータが残っている場合、初回にv8へ取り込みます。
・同じ端末・同じブラウザ・同じ公開URLで利用してください。
・定期的に「バックアップ」ボタンからJSONファイルを保存してください。

【今回の検証内容】
・GitHub PagesのサブフォルダーURLで使える相対パス
・HTML / JavaScript / manifest の構文
・Service Workerの登録範囲、更新、オフライン用キャッシュ
・192px / 512pxアイコンの形式と寸法
・始業直後に終業しても始業GPS結果が勤務記録へ反映される処理
・各作業の開始／終了GPS、作業切替時の共通位置、緯度経度と取得時刻の表示
・旧v6 / v7データの移行処理
