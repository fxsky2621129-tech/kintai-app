勤怠・改善基準チェッカー v8.6.3（2026-09-12）

公開先：https://fxsky2621129-tech.github.io/kintai-app/

GPSの改善
・始業・終業の打刻を即時保存し、最大60秒測位します。精度20mを目標に位置を改善します。
・最初に取れた座標を先に保存します。住所変換に失敗しても位置情報を保持します。緯度・経度は画面・印刷・CSVに表示しません。
・高精度測位で取得できない場合は、ブラウザの通常精度測位も試します。通常精度の取得が失敗した場合は、60秒の範囲内で最大3回試します。
・低精度時の「位置を確認してください」という案内は表示しません。精度の数値は引き続き表示します。
・保存済みの座標がある「再取得」は住所のみ更新し、過去の打刻位置を現在地で上書きしません。
・未取得の記録を後から測位した場合は「打刻後の再取得位置」と表示します。
・通信復旧・アプリ再起動時、直近20勤務の住所未取得データを保存済み座標から再照会します。
・測位完了前に画面を閉じると、端末によって処理が中断されます。測位中は画面を開いておいてください。

Androidで未取得になる場合
・端末の位置情報と、Chromeでこのサイトへの位置情報許可を確認してください。
・屋外や窓際で再取得し、表示された精度を確認してください。
・ブラウザや端末から位置情報を取得できない状態をアプリだけで解消することはできません。

改善基準チェック
・総合欄・勤務履歴・CSVに、該当する違反、注意、判定待ちを全件表示します。
・通常ルールの連続運転4時間、休息最低9時間、24時間拘束15時間、必要休憩、2日平均9時間、2週間88時間を判定します。
・連続運転は短い勤務間隔や日跨ぎでも引き継ぎます。30分以上の休息でリセットします。
・厳格判定として、荷役・待機などは休憩として自動算入しません。この取扱いによる連続運転超過は総合欄に明示します。
・10分未満の休憩は要確認、3回以上の連続は違反として表示します。
・勤務前と勤務後の休息を表示し、次の始業が未登録なら勤務後の休息は判定待ちです。
・13時間超の拘束、9時間以上11時間未満の休息は、違反と混同せず注意として表示します。
・14時間超が月～日の週3回以上、または連日の場合も注意表示します。
・月間284時間、暦年3300時間の通常上限を超えた日から累計超過を表示します。
・2日平均は翌日の記録が未確定なら、まだ確定できない判定を適合にしません。

計算の前提
勤務は始業日に計上し、月跨ぎでも始業月に集計します。年の集計は1月～12月です。
記録のない日は0時間として扱います。全勤務を登録しない場合、超過を見逃す可能性があります。
労使協定、長距離運送、フェリー、2人乗務、分割休息、予期し得ない事象などの特例は自動適用しません。
厳格判定は例外条件を含む法令適合性全体の確定判断ではありません。
時間外等の賃金計算は従来の概算方式を維持しています。

データと更新
既存の保存キーを維持しています。同じ端末・ブラウザ・公開元でデータを引き継ぎます。
更新前にJSONバックアップを保存してください。サイトデータの削除はしないでください。
画面上のバージョンがv8.6.3になるまで再読み込みし、必要ならアプリを閉じて開き直してください。
ローカル確認はHTTPSまたはlocalhostで配信してください。
