勤怠・改善基準チェッカー v8.5.1

【更新方法】
1. 現在のアプリで「バックアップ」を押し、JSONファイルを保存してください。
2. このZIPを展開し、今までと同じ配信先のアプリファイル一式を差し替えてください。
   index.html / app.js / style.css / sw.js / manifest.webmanifest / icon-192.png / icon-512.png
3. 通信可能な状態でアプリを開き直してください。必要に応じて、いったんすべてのアプリ画面を閉じて再度開いてください。
4. 画面下部のバージョンが「v8.5.1」になったことを確認してください。

保存キーはv8.5と共通です。同じブラウザ・同じ配信元なら既存データを引き継ぎます。
配信元やブラウザを変える場合は、保存したJSONを「復元」してください。
ZIPを展開したindex.htmlの直接起動ではPWAやGPSの動作条件を満たさない場合があります。
これまでのHTTPS配信先、または開発時のlocalhostで使用してください。

【修正した8項目】
・復元内容を保存前に検証。保存途中の失敗は元データへ戻し、処理中断時も次回起動で復旧。
・所定時間が日付をまたぐ夜勤の時間外計算を修正。
・同じ始業日の複数勤務を合算して時間外と必要休憩を計算。
・履歴のIDをHTMLやonclick文字列へ埋め込まず、安全なイベント登録に変更。
・GPS取得完了前に終業しても、勤務IDを使って始業GPSを履歴へ保存。
・始業と同時に休息を終了し、勤務と休息の重複を防止。
・市区町村取得失敗後の再試行、通信復旧時の再取得、通信タイムアウトを追加。
・休憩以外の運転中断や短い中断を画面・CSVへ表示。短い中断の連続回数判定を修正。

【集計の扱い】
勤務時間は従来と同じく始業日に計上します。月をまたぐ勤務も始業月にまとめます。
時間外は、同日の合算実働から所定実働を引いた時間と、所定時間外の実働の大きい方です。
所定時間外の実働を優先して時間外とし、追加の超過分は所定内の遅い時間帯へ割り当てます。
「概算時間外等」は時間外賃金に、全深夜実働の割増分を加えた概算です。
通常の基本給全額、休日割増、週単位の時間外判定、会社固有の賃金規程は含みません。
休息期間の改善基準判定は、終業から次の始業までの間隔で行います。
休憩以外の運転中断や10分未満の中断は「要確認」として表示します。
10分未満の中断が3回以上連続すると「違反」を表示します。
例外条件を含む法令適合性全体を保証するアプリではありません。

【復元の検証】
不正なID、重複するID、不正な日時・作業区分・設定、重複した勤務や作業区間などを拒否します。
検証できない形式のバックアップは保存せず、理由を表示します。
以前の不正な復元ですでに失われたデータは、この修正版だけでは復元できません。
その場合は正常なバックアップを使用してください。

【検証結果】
回帰テスト33件、Chromeブラウザ検証12件、計45件が通過しました。
打刻・夜勤・複数勤務・復元失敗と保存失敗・GPS遅延・通信再試行・中断判定を確認。
画面操作、CSV/JSON出力、390px幅表示、サーバー停止後のキャッシュ再読み込みも確認。
GPSと住所APIはテスト用の応答を使用しています。
実機GPSの測位精度、スマートフォンへのインストール操作、各端末の印刷結果は未検証です。
